Статус на 30.09.2026: **реализация и автоматические проверки завершены**.

только до 14:00. Рабочая копия содержит незакоммиченные изменения.
Ручная проверка на устройстве остаётся открытой: устройство не подключено.

## Задача и направление

Сделать светлую и тёмную темы согласованными: мягкая зелёная основа, тёплый
персиковый для смеси, приглушённый синий для сна. Сохранить знакомый характер
приложения. Основной текст и цифры — нейтральные, цвет выделяет действие,
категорию или состояние. Обычные карточки спокойные; большие цветные заливки
оставить для важных состояний.

Объём: тема Compose, общие компоненты, четыре экрана, диалоги, графики,
экран восстановления и оформление виджетов. Сначала выполнить Compose, затем
виджеты как отдельный связный этап. Не менять расчёты, справочные значения,
хранение, синхронизацию, действия кнопок и выбор темы. Единственное изменение
временного условия напоминаний — прекращение мигания витамина D с 14:00,
описанное ниже; остальные пороги сохранить.
Не добавлять шрифтовые зависимости или новый дизайн-фреймворк.
Не публиковать APK и не создавать релизный тег.

## Назначение цветов компонентам

| Элемент | Фон | Текст / значимые иконки |
| --- | --- | --- |
| Страница, системные панели | background | onBackground; яркость системных иконок по выбранной теме |
| Обычная карточка, карточка графика | surfaceContainerLow | onSurface; описание onSurfaceVariant |
| Вложенная область графика | surface | onSurface; оси/подписи onSurfaceVariant |
| Диалог, меню, sheet | surfaceContainerHigh | onSurface; подсказки onSurfaceVariant |
| Нижняя навигация | surfaceContainer | выбранный текст primary, остальные onSurfaceVariant |
| Индикатор выбранной вкладки | primaryContainer | выбранная иконка onPrimaryContainer |
| Главное действие / молоко | primary | onPrimary |
| Действие «Смесь» | secondary | onSecondary |
| Действие сна | tertiary | onTertiary |
| Вторичное действие той же категории | соответствующий *Container | соответствующий on*Container |
| Выбранный чип | primaryContainer | onPrimaryContainer; отметка выбора |
| Невыбранный чип | surface | onSurfaceVariant; граница outline |
| Ошибка, удаление, непринятый витамин | errorContainer | onErrorContainer; выделенное опасное действие error/onError |
| Подтверждённое действие, витамин принят | primaryContainer | onPrimaryContainer и отметка выполнения |
| Информационная справка | tertiaryContainer | onTertiaryContainer |
| Предупреждение «Важно» в настройках | secondaryContainer | onSecondaryContainer |
| Snackbar | inverseSurface | inverseOnSurface; действие inversePrimary |

Для обычных Card явно задать containerColor и contentColor: заголовки и значения
не должны случайно наследовать цвет второстепенного текста из CardDefaults.
На цветном контейнере использовать его on*Container; второстепенный текст
различать размером и начертанием, не снижением alpha.

Нейтральные границы полей — outline; разделители и декоративная сетка —
outlineVariant. Последние могут быть малоконтрастными, если без них понятен
интерфейс. Существенные границы контролов и отметки выбора — минимум 3:1
относительно соседнего фона. Не требовать 3:1 между каждой карточкой и страницей.

В RastiApp убрать градиент страницы; задать Scaffold.background через
containerColor = background. Навигация непрозрачная, tonalElevation = 0.dp,
чтобы оттенок не изменялся поверх выбранного токена. Сохранить форму и отступы.

Поля ввода: обычный текст onSurface, placeholder/label onSurfaceVariant,
фокус primary, ошибка error и текст сообщения, selection через стандартные
механизмы Material. Disabled оставить стандартным Material-состоянием;
низкий контраст допустим только для действительно недоступного действия.
Pressed/focused должны быть видимы, ripple и TalkBack не отключать.

## Графики и бутылочка

Сохранить смысл текущих серий: молоко primary, смесь secondary, сон tertiary,
бодрствование secondary. Использование tertiary для нормы питания оставить
в рамках графика питания; подпись и рисунок отличают норму от ряда сна.
Фон графика surface, подписи onSurfaceVariant, значимые линии outline.

Цвета молока и смеси дополнять разной формой маркеров/штриховкой, сон и
бодрствование — подписями; существующие обозначения легенды сохранить.
Норма — полупрозрачная область и пунктирная граница, не ещё один сплошной ряд.
Текст легенды предпочтительно onSurface, рядом цветной маркер.
Декоративный коридор может иметь alpha, его подпись — всегда непрозрачная.

В GrowthCanvas точка primary с центром onPrimary. На графиках проверить
пересечения, область нормы, отсутствие и наличие данных, выбранную запись.
Внутри столбцов молока и смеси использовать onPrimary/onSecondary.

BottleAmountPicker: основной объём onSurface на непрозрачной плашке surface,
единицы onSurfaceVariant без alpha. Жидкость secondaryContainer допустима;
контур бутылки и значимые деления outline без понижения alpha. Второстепенные
деления можно оставить мягкими, если объём читается независимо от них.
Canvas-текст должен учитывать fontScale; не зафиксировать размер в пикселях.

## Виджеты: отдельный этап реализации

RemoteViews не наследует Compose-тему. Сохранить существующий режим тёмных
виджетов в этом задании, но привести их к **тёмной колонке этой палитры**.
Не добавлять автоматическое следование теме приложения или системы: это
отдельное поведение, требующее работы с ресурсами/обновлениями всех виджетов.
Таким образом, требование двух тем относится к интерфейсу приложения;
виджеты после этого этапа остаются тёмными по явному решению.

Создать `res/values/widget_colors.xml` с именованными ресурсами:

widget_on_surface = dark onSurface, widget_on_surface_variant = dark onSurfaceVariant;
добавить пары milk = dark primaryContainer/onPrimaryContainer,
formula = dark secondaryContainer/onSecondaryContainer,
sleep = dark tertiaryContainer/onTertiaryContainer,
alert = dark errorContainer/onErrorContainer.
Для attention использовать dark secondaryContainer/onSecondaryContainer,
для ok — dark primaryContainer/onPrimaryContainer.

Заменить HEX в drawable/layout/styles и Color.rgb/Color.WHITE в коде на эти
ресурсы; фон dashboard сделать однотонным. Прозрачные белые панели заменить
на widget_surface. Все пары статуса менять целиком, включая текст.
Переход wakeAttention не должен смешивать непроверенный цвет текста:
сохранить расчёт состояния, применить контрастную пару для его отображения.

## Проверки и критерии готовности

Цель проекта: текст >= 4.5:1, значимые графические элементы >= 3:1.
Проверять итоговые цвета после alpha, смешивания и tonal elevation.
Это критерии этого задания; математическая проверка палитры не заменяет UI-проверку.

При подготовке документа независимо рассчитаны 86 непрозрачных пар:
основные on*/фон, оба цвета текста на 10 нейтральных поверхностях, акцентный
текст на surface и surfaceContainerLow, onSurface на четырёх цветных контейнерах,
inverse-пары. Минимум 4.77:1 (light tertiary на surfaceContainerLow).
Результаты и формула — [theme-contrast-audit.md](theme-contrast-audit.md).
Анимации, disabled и новые виджеты этой проверкой не охвачены.

В текущем VitaminDReminder при pulse = 1 светлая смесь
lerp(#BA1A1A, #FFDAD6, 0.38) ≈ #D46361: белый текст даёт **3.65:1**,
даже без дополнительной прозрачности. Регрессионная проверка должна покрывать
shouldPulse true/false и фазы 0, 0.25, 0.5, 0.75, 1 с реальным композитингом.

Для ограничения мигания проверить 13:59:59 (мигает), 14:00:00 и 14:00:01
(статичен), принятый витамин до/после 14:00 (напоминания нет), прошлую/будущую
дату (не мигает), другой витамин без D (не подавляет напоминание), переход
через полночь и изменение локальной даты при смене часового пояса.
В UI-тесте с управляемым временем открыть экран до 14:00, перейти через границу
и убедиться, что анимация остановилась, блок остался и нажатие работает.
Отдельно проверить возвращение из фона после 14:00. Использовать тестовые часы
и синтетические данные, без реального ожидания. Новый тест условия запустить
в Targeted до screenshot-проверок и Full.

Матрица: обе темы, 320/360dp, fontScale 1.0/1.3. Автоматические снимки теперь
