# Визуальные эталоны

PNG создаются `ScreenScreenshotTest` и `WidgetScreenshotTest` на Robolectric API 28
с native graphics, фиксированной плотностью mdpi и локалью en-US. Пользовательский
текст приложения остаётся русским. Матрица: светлая/тёмная тема, ширина 320/360 dp и шрифт 1.0/1.3; основные экраны, бутылка, восстановление и формы. Дашборд проверяется в трёх размерах, остальные виджеты — в двух размерах или нескольких состояниях. Данные синтетические, время фиксировано. Поля формы витамина D снимаются вне Android Dialog: Robolectric не достигает idle для TextField внутри Dialog.

Запись и проверка: `docs/testing.md`. Файлы `*-actual.png`, `*-expected.png` и
`*-diff.png` хранятся только в `app/build/reports/screenshots/`, не в эталонах.
Допуск: до 0.1% пикселей с отличием канала более 3/255. Отличия сверх допуска
требуют просмотра; не увеличивать допуск вместо исправления причины.

Эталоны основных экранов используют наполненный синтетический дневник. При изменении конкретной карточки проверять её состояние и соответствующие позиции прокрутки. Снимки не заменяют
проверку прокрутки, действий, TalkBack и настоящего Android-лаунчера.
