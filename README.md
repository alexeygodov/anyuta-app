# Анюта

Небольшое Android-приложение для семейного учёта питания, витаминов, роста и веса ребёнка. Работает без собственного сервера: данные сохраняются на телефоне и автоматически синхронизируются с отдельным приватным GitHub-репозиторием.

## Что уже есть

- питание и питьё с количеством и временем;
- быстрые кнопки «Смесь» и «Молоко» с вводом миллилитров;
- всегда видимый суточный график измеренного молочного питания; справочный диапазон добавляется после ввода даты рождения и веса;
- отметки о витаминах;
- числовая доза витамина и отдельная единица измерения (`2` + `капля`);
- усиленное мигающее напоминание о витамине D до приёма;
- рост, вес и заметка за день;
- учёт сна кнопками «Уснула» и «Проснулась», автоматический расчёт длительности, быстрый ввод завершённого сна без нажатия «Уснула» и редактирование интервала;
- интервалы сна на суточном графике и синхронизация сна между телефонами;
- основной Android-виджет с крупными данными последнего кормления, расчётной порции, сна и витамина D;
- отдельный Android-виджет с суточной шкалой кормлений и сна;
- компактные размеры обоих виджетов с ручным изменением по ширине и высоте; график заполняет доступное место;
- быстрые кнопки основного виджета для молока, смеси и сна без лишних переходов;
- единый современный дизайн приложения со светлой и тёмной темами, мягкими карточками и компактной навигацией;
- выбор даты, вертикальные барабаны часов и минут с шагом 5 минут и редактирование записей из истории;
- ввод объёма молока и смеси ползунком с шагом 5 мл;
- пульсирующее напоминание о витамине D над питанием и отметка двух капель одним нажатием;
- история и короткая сводка за 7 дней;
- недельный график молочного питания с разбивкой на молоко и смесь и суточными границами;
- недельная карта сна по дням и времени суток с корректным разделением сна через полночь;
- графики роста и веса с коридором `−2…+2 SD` WHO для возраста 0–5 лет;
- график скорости роста между измерениями в сантиметрах за 30 дней;
- фактический темп роста и веса между замерами, без предсказания дат скачков;
- личный график прививок со статусами «запланирована» и «сделана»;
- автоматическая двусторонняя синхронизация при запуске, каждые 5 секунд при открытом приложении, после изменения данных и переключения вкладок;
- отдельные переключатели уведомлений о долгом перерыве в кормлении, витамине D и новых записях с другого телефона;
- объединение записей двух телефонов и повтор записи при конфликте;
- token хранится зашифрованным ключом Android Keystore;
- сборка APK в GitHub Actions.
- проверка, скачивание и запуск установки новой версии из GitHub Releases.

Приложение не является медицинским изделием и не ставит диагнозы.

С версии 0.12.0 вместо календаря предполагаемого беспокойства показывается фактический темп роста и веса. Замеры объединяются в интервалы не короче 7 дней, скорость считается в г/день или см/30 дней. Это описательная статистика, не прогноз скачка и не диагноз; сравнение с возрастными ориентирами остаётся на графиках ВОЗ. [NHS: наблюдение за ростом и весом](https://www.nhs.uk/baby/babys-development/height-weight-and-reviews/baby-height-and-weight/).

В недельном графике сна подписаны длительности сна и пауз между записями. Короткие отрезки доступны в подробностях выбранного дня. Паузы более 12 часов считаются недостатком данных, а не непрерывным бодрствованием; пересекающиеся сны не удваивают итог. На главной строка бодрствования постепенно краснеет после личного порога (настройки → «Бодрствование»; начальная настройка 120 минут, 0 выключает подсветку). Это напоминание, не медицинская рекомендация: [режим сна у каждого ребёнка индивидуален](https://www.nhs.uk/baby/caring-for-a-newborn/helping-your-baby-to-sleep/).

Ввод бутылкой сохранён: добавлены точные кнопки −5/+5 мл и управление для TalkBack. Светлая и тёмная палитры задают все поверхности карточек и диалогов; подпись объёма остаётся контрастной при любом наполнении бутылки. Дневник навыков не добавляется.

## Ориентир объёма питания

Для возраста от одной недели до шести месяцев приложение показывает справочный диапазон смеси `150–200 мл/кг в сутки` и середину диапазона `175 мл/кг` как отметку на шкале. Используется последнее измерение веса не позднее выбранной даты; рост и пол в этот расчёт не входят.

Это не назначение и не цель, которую нужно обязательно достигнуть. Диапазон может отличаться для недоношенных, больных детей и по рекомендации врача. Прямое грудное вскармливание не переводится в миллилитры: WHO рекомендует кормление грудью по требованию. Источники: [NHS — formula feeding](https://derbyshirefamilyhealthservice.nhs.uk/our-services/0-5-years/infant-feeding-and-nutrition/formula-feeding), [WHO — breastfeeding](https://www.who.int/health-topics/breastfeeding).

## Репозитории

Рекомендуется использовать два репозитория:

1. `anyuta-app` — этот проект, только исходники.
2. `anyuta-data` — приватный репозиторий с семейными данными.

Создайте `anyuta-data` как **Private repository** и включите создание `README`. После первой синхронизации структура будет такой:

```text
profile.json
data/
  2026/
    08/
      2026-08-18.json
```

## Настройка доступа к данным

В приложении нажмите **«Создать токен на GitHub»** или на GitHub откройте:

```text
Settings → Developer settings → Personal access tokens → Fine-grained tokens
```

Для token задайте:

- Repository access: только приватный `anyuta-data`;
- Repository permissions → Contents: `Read and write`;
- разумный срок действия.

Нажмите **Generate token** и сразу скопируйте полученную строку: обычно она начинается с `github_pat_`. Именно эту строку нужно вставить в поле **«Токен доступа GitHub»** в приложении. Это не SSH-ключ, не пароль от GitHub и не ключ подписи APK.

В приложении введите владельца `alexeygodov`, репозиторий `anyuta-data`, ветку `main` и token. Публичные обновления из `anyuta-app` скачиваются без token. У каждого взрослого желательно иметь свой token для `anyuta-data`. Он хранится только на конкретном телефоне в зашифрованном виде. Не отправляйте token в чат и не добавляйте его в исходники, JSON или GitHub Actions secrets.

## Получение APK без Android Studio

1. Загрузите исходники в репозиторий `anyuta-app`.
2. Откройте вкладку **Actions**.
3. Выберите **Build Android APK** → **Run workflow**.
4. После завершения скачайте artifact `anyuta-...` и распакуйте APK.

Без настроенной подписи workflow создаёт debug APK. Он устанавливается на телефон, но APK из разных запусков может иметь разные ключи, поэтому для обновлений настройте постоянную release-подпись.

## Обновление из приложения

В настройках приложения нажмите **«Проверить обновление»**. Приложение читает последний GitHub Release, скачивает его APK в свой временный каталог и открывает системное окно установки Android. При первом обновлении Android попросит разрешить установку из источника «Анюта».

GitHub Release создаётся автоматически при отправке тега версии, например:

```powershell
git tag v0.4.0
git push origin v0.4.0
```

Для установки поверх уже установленной версии все APK обязательно должны быть подписаны одним постоянным ключом. Поэтому перед использованием встроенного обновления настройте release-подпись ниже и не меняйте ключ.

## Постоянная подпись APK

Сгенерируйте ключ один раз и сохраните резервную копию вне GitHub:

```powershell
keytool -genkeypair -v -keystore anyuta-release.jks -alias anyuta -keyalg RSA -keysize 2048 -validity 10000
```

Получите Base64 и скопируйте его в буфер:

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("anyuta-release.jks")) | Set-Clipboard
```

В `anyuta-app → Settings → Secrets and variables → Actions` добавьте:

- `SIGNING_KEY_BASE64` — содержимое буфера;
- `KEYSTORE_PASSWORD`;
- `KEY_ALIAS` — обычно `anyuta`;
- `KEY_PASSWORD`.

Следующий workflow соберёт подписанный release APK. Файл `anyuta-release.jks` и пароли нельзя коммитить. Если ключ потерять, Android не позволит устанавливать новые версии поверх старой.

Workflow намеренно не публикует version tag без этих Secrets: временная debug-подпись меняется между GitHub runners и ломает обновление поверх установленного APK.

## Локальная сборка

Нужны JDK 17 и Android SDK 37:

```powershell
.\gradlew.bat assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`.

## Справочные данные WHO

CSV в `app/src/main/assets/who/` получены из официальных расширенных таблиц WHO:

- https://www.who.int/tools/child-growth-standards/standards/length-height-for-age
- https://www.who.int/tools/child-growth-standards/standards/weight-for-age

Скрипт `tools/extract_who.py` оставлен для воспроизводимого повторного преобразования исходных XLSX.

## Приватность

Данные в data-репозитории хранятся в обычном JSON и видны всем, у кого есть доступ к приватному репозиторию. Не используйте публичный data-репозиторий. Для первой версии желательно указывать псевдоним ребёнка и не хранить медицинские документы или фотографии.
